Technical project

Bimanual Robot Learning for Demonstration-Based Manipulation

RoboticsImitation LearningBimanual ManipulationTeleoperationSimulation

Executive Summary

This active university team project explores how a bimanual robotic system can learn manipulation tasks from human demonstrations. The work combines human-guided data collection, synchronized visual and robot observations, supervised behavior cloning, and evaluation in simulation and on physical hardware. My current contribution focuses on system-level preparation and defining a reliable workflow for data collection, training, and evaluation.

Project Context & My Role

Traditional robot programming often requires individual motions to be specified manually and can be difficult to adapt when objects or starting conditions change. This project investigates demonstration-based learning as an alternative: a person demonstrates a manipulation task and a task-specific policy learns from those examples.

The work is an active university research team project. My current responsibilities include technical preparation, analysis of the overall learning workflow, specification of the data pipeline, investigation of control and simulation requirements, and preparation for model integration. Implementation responsibilities will develop as the project progresses.

Technical Approach

Human-guided manipulation demonstrations will be recorded together with synchronized visual observations and robot-state information. The collected streams will be converted into aligned training episodes and used for supervised behavior cloning. Policies will then be evaluated in simulation and, when appropriate, on the physical system.
